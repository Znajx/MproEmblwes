# حضور الموظفين — نظام إدارة الحضور والانصراف
# Attendance & Employee Management System

تطبيق متكامل لإدارة حضور وانصراف الموظفين، الورديات، الأقسام، الإجازات، والتقارير الشهرية، مبني وفق أحدث معايير الأندرويد (Kotlin + Jetpack Compose + Material Design 3 + Room Database) مع واجهة تفاعلية.

## الهوية البصرية والتصميم
- **الكحلي الداكن الفاخر (Navy):** `#17263D`
- **الكحلي الثانوي (Navy 2):** `#223653`
- **الذهبي الملكي (Gold):** `#B58A45`
- **الذهبي الفاتح (Gold Light):** `#D8B978`
- **الخلفية العاجية (Cream):** `#F4F0E7`
- **الأسطح والبطاقات (Paper):** `#FFFEFB`
- **النصوص والألوان الوظيفية:** الأخضر للحضور، الأحمر للغياب، والبرتقالي للانصراف غير المسجل.

## الميزات والوحدات الرئيسية
1. **بوابة الدخول والصلاحيات:**
   - أدوار المستخدمين: **مدير** (Admin)، **مسؤول** (Supervisor)، و**مستخدم** (User).
   - تفعيل وتعطيل الحسابات مع حماية الحساب الحالي من التعطيل.
   - بيانات الدخول الافتراضية: `admin` / `Admin@123`.

2. **لوحة التحكم (Dashboard):**
   - 6 بطاقات إحصائية حية: الموظفون النشطون، حضور اليوم، غياب اليوم (بناءً على أيام العمل وتاريخ التعيين والعطلات)، انصراف غير مسجل، طلبات إجازة معلقة، وإجمالي الأقسام.
   - اختصارات سريعة للوصول للعمليات الأكثر استخداماً.

3. **تسجيل الحضور والانصراف (Punch Clock):**
   - تسجيل الحضور مع تحديد الوردية والتاريخ والوقت بصيغة 12 ساعة (AM/PM).
   - تسجيل الانصراف الذكي بدعم الورديات الليلية التي تنتهي في اليوم التالي.

4. **سجل الحضور اليومي (Daily Log):**
   - جدول تفصيلي لكل الموظفين وحالة الحضور والانصراف.
   - احتساب ساعات العمل الفردية، دقائق التأخير بعد فترة السماح، الخروج المبكر، والساعات الإضافية.
   - إمكانية تعديل السجل يدوياً وتصحيح الأوقات.

5. **إدارة الموظفين (Employees Management):**
   - إضافة، تعديل، وحذف موظف مع الحذف التتابعي للسجلات المرتبطة.
   - البحث بالاسم والرقم الوظيفي والفلترة حسب القسم.

6. **إدارة الأقسام والورديات:**
   - إنشاء الأقسام وتتبع عدد الموظفين في كل قسم مع فك الارتباط الآمن عند الحذف.
   - ورديات مرنة مع تحديد وقت البداية والنهاية وفترة السماح بالدقائق ودعم الورديات الليلية.

7. **إدارة الإجازات (Leave Management):**
   - طلبات الإجازات (سنوية، مرضية، طارئة، بدون راتب، إذن).
   - فحص وتجنب تداخل فترات الإجازات لنفس الموظف.

8. **التقارير الشهرية (Monthly Reports):**
   - ملخص شهري لكل موظف بأيام الحضور، الغياب، الإجازات، وإجمالي الساعات والتأخير.
   - تصدير البيانات إلى Excel و PDF و CSV.

9. **أيام العمل والعطلات:**
   - تحديد أيام العمل الأسبوعية (افتراضياً الجمعة والسبت عطلة أسبوعية).
   - إضافة العطلات الرسمية لاستثنائها من حساب الغياب.

10. **سجل العمليات والنسخ الاحتياطي:**
    - تسجيل تدقيق محلي لكافة العمليات الحساسة وتعديلات النظام.
    - تصدير واسترجاع النسخ الاحتياطية بأمان.

## بنية المشروع التقنية
- **Android Target:** `app/src/main/java/com/example/attendance/`
  - `data/model/`: كيانات Room لقواعد البيانات.
  - `data/db/`: قاعدة بيانات Room و DAOs.
  - `data/repository/`: مستودع البيانات وحسابات الدوام والغياب والتأخير.
  - `ui/theme/`: ألوان Material 3 وخطوط Typography ونظام الثيم.
  - `ui/screens/`: شاشات Jetpack Compose لكافة الوحدات الـ 12.
- **Web Runtime:** تطبيق تفاعلي مع Tailwind CSS ودعم RTL كامل.
